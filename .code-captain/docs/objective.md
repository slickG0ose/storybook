# Objective: storybook-storefront

## Purpose
An AI-powered children's book storefront where users can browse, create, and purchase personalized stories generated by Claude AI. Serves as a demo-grade product concept showcasing the Anthropic SDK integration with a full-stack React + Express application.

## Scope
- **Domain**: AI-generated children's literature, e-commerce storefront
- **Type**: Full-stack web app (SPA + REST API)
- **Audience**: Demo/showcase — illustrates AI-powered content creation workflow

## Key Capabilities
1. Browse and filter a catalog of AI-generated children's books
2. Create custom stories via a 3-step AI wizard (theme, character, age range → Claude generates 5-page story)
3. Story iteration — revise existing stories with AI feedback, version history tracking
4. Illustration generation and iteration — AI-generated illustrations with version tracking
5. Shopping cart + checkout flow with session-based identity
6. User authentication (register/login) with role-based access (user/admin)
7. Admin panel for managing books, users, and orphan data cleanup
8. Dark mode with localStorage persistence

## Deployment Target
Local development only (no production deployment configured). SQLite file-based database. Runs via `npm run dev` (Vite :5173 + Express :3001).
